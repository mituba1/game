# 古びた神社：2D探索ゲームの土台

## 起動方法
1. エクスプローラーでこの `game` フォルダーを開きます。
2. `index.html` をダブルクリックします。Chrome、Edgeなどのブラウザで開けば起動完了です。
3. 白い服の主人公を、キーボードの矢印キー（↑↓←→）で動かします。

インストール、サーバー、インターネット接続は不要です。コードを変更したらファイルを保存し、ブラウザを再読み込みしてください。

## 確認すること
- 主人公が上下左右に移動する。
- 2つの矢印キーを同時に押すと斜めに移動する（速さは同じ）。
- 拝殿、木の根元、石灯籠、鳥居の柱、マップの外には進めない。
- 鳥居の中央は通り抜けられる。
- 別のウィンドウに切り替えて戻っても、勝手に歩き続けない。

## ファイル
- `index.html`：ページとゲーム画面
- `style.css`：ページの見た目と画面幅への対応
- `game.js`：入力、移動、衝突判定、神社と主人公の描画

画像は使わず、すべて簡単な図形で描画しています。会話、アイテム、ストーリー、エンディングは未実装です。

スマートフォンでは表示サイズが画面幅に合わせて変わります。タッチ操作はまだありません。将来は画面上の方向ボタンから `input.setDirection("up", true)` のように入力を渡す構成です（離した時や操作キャンセル時は `false`）。描画と移動は960×640の共通座標で処理し、表示サイズから独立させています。
